# Glossary

Short definitions used across the product and docs.

| Term | Meaning |
|------|---------|
| **Active resume** | The CV version used for new analyses |
| **Analysis** | One saved match result (`analyses` row) |
| **Application** | Tracker card for a role (`applications` row) |
| **Application pack** | Combined download of report + CV + bullets + letter |
| **Artifact** | Generated career-tool output (bullets, full CV, letter, plan, interview prep) |
| **Batch analyze** | Queue of pastes or URLs run one after another |
| **eve** | Agent framework that runs skills and tools |
| **Follow-up** | Reminder date on an Applied / Interview card (`followUpAt`) |
| **History** | Dashboard list of analyses |
| **Job metadata** | Optional company, location, salary on a posting |
| **Job posting** | Stored job text / URL metadata |
| **Match %** | Overall fit score from `score_match` |
| **Re-score** | New analysis linked via `previousAnalysisId` |
| **Seniority fit** | `under` / `match` / `over` vs role level |
| **Skill category** | Grouped scores for the radar chart |
| **Tailored CV** | Full resume draft artifact (`tailored_cv`) |
| **Tracker** | Kanban of application statuses |
| **Untitled role** | Fallback title when none could be extracted |
